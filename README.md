# Agentic RAG Research Assistant


An AI-powered Retrieval-Augmented Generation (RAG) application built with LangGraph and LangChain for document question answering using semantic retrieval and vector search.

## Features

- Document Q&A using Retrieval-Augmented Generation.
- LangGraph stateful workflow orchestration.
- FAISS vector search for semantic retrieval.
- LangChain prompt pipeline.
- OpenAI embedding and chat model support.
- Local Python implementation.

## Tech Stack

Python • LangChain • LangGraph • FAISS • OpenAI • Vector Search
